# 血氧监测 App 使用说明（v3）

## 文件

- `血氧监测_v3.apk`：Android 6.0 及以上，包名 `com.bme.ppg`，debug 签名。
- 源码：`MainActivity.java`。
- 本版本沿用 v2 的 debug 签名，可直接覆盖安装；若手机提示签名不一致，先卸载旧版再安装（卸载会清除 App 内记录）。

## 主界面

- 顶部右侧状态胶囊显示 `未连接` / `已连接`。
- 状态胶囊左侧新增 `记录` 按钮，点击进入 App 内的“数据记录”页。
- 脉率颜色：
  - 绿色：当前脉率在固件同步的正常区间内；
  - 红色：低于下限或高于上限；
  - 灰色 `--`：还没有有效脉率。
- 区间由固件 `0x04` 帧每秒同步；默认 `60–100 bpm`，可在板子第 4 页 `4/4 SETTINGS` 用 S1–S4 修改，修改后手机端自动跟随。

## 记录

- 底部 `开始记录`：开启后每 1 秒保存一条本机记录；再次点击变为 `停止记录`。
- 跌倒事件会自动记录，不受“开始记录”开关限制；连接状态下点击 `模拟跌倒` 也会生成一条跌倒记录。
- 顶部 `记录` 进入记录页：
  - 显示总条数、跌倒次数和当前 PR 正常区间；
  - 每条包含时间、血氧、脉率、灌注指数、状态、姿态；
  - 脉率按记录当时的上下限着色，越界为红色；
  - 跌倒记录单独成条，红色卡片和“跌倒”标签；
  - 默认显示最近 300 条，最多保留 50000 条；
  - 可点 `刷新`，也可点 `清空` 删除全部本机记录（需确认）。

## 数据保存在哪里

- 全部记录保存在 App 私有 SQLite 数据库 `ppg_records.db`，不再写 CSV，也不需要去 `Android/data/...` 文件夹翻文件。
- App 内直接查看；卸载 App 会同时删除这些记录。

## 连接注意

- JDY-31 同一时刻只能连接一台主设备。手机连接前，电脑上位机要先点“断开”，否则手机连不上。
- 手机先系统蓝牙配对 JDY-31（PIN `1234`），再回到 App 点右上角状态胶囊选择设备。
- 串口参数：`9600 8N1`，经典 SPP UUID。

## 记录字段

| 字段 | 说明 |
| --- | --- |
| 时间 | 手机本地时间 |
| 血氧 SpO₂ | 百分比，无效显示 `--` |
| 脉率 PR | bpm，按当时区间绿/红，无效显示 `--` |
| PI | 灌注指数，百分比 |
| 状态 | 空闲/测量中/信号弱/跌倒报警 |
| 姿态 | Pitch / Roll，单位度 |
| 跌倒 | 独立事件行，红色“跌倒”标签 |

## 版本

- v2：CSV 记录、脉率白色、无 App 内记录页。
- v3：本机 SQLite 记录页、顶部记录入口、脉率绿/红、跌倒记录、`0x04` 区间同步。

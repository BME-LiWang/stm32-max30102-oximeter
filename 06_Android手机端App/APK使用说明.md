# 手机端 APK 使用说明（v2）

安装包：`血氧监测.apk`（527 KB，debug 签名）
源码：`MainActivity.java`（45 KB，单文件实现，无第三方依赖）

## v2 相比初版改了什么

| 类别 | 改动 |
|---|---|
| 视觉 | 全新应用图标（自适应图标，桌面不再是安卓小人）；圆角卡片 + 描边；自定义按钮（描边/实心两种）；深色科技配色（青/红/绿三色语义） |

## 一、安装

1. 把 APK 传到手机（微信文件传输助手 / 数据线 / 网盘）
2. 点击安装。已装过初版的话可以直接覆盖安装（签名一致），不用卸载
3. 若提示"未知来源"，允许本次安装

系统要求：Android 6.0 及以上。

## 二、第一次使用：先配对（不能跳）

App 只列出**系统已配对**的设备，不会自己扫描。

1. 板子上电，JDY-31 指示灯闪烁
2. 手机 **设置 → 蓝牙 → 搜索新设备**
3. 选择 `JDY-31`（或 `JDY-31-SPP`），PIN 输入 `1234`（少数模块 `0000` / `123456`）
4. 回到 App，点右上角「未连接」胶囊

首次打开会有一步引导提示，看过一次后不再出现。

## 四、跌倒报警（v2 新增联动）

板子判定跌倒后（或你点「模拟跌倒」）：

1. 手机上弹出**全屏红色遮罩**，显示「检测到跌倒」
2. 手机**连续振动**（0.4s 震 / 0.2s 停 ×2 + 长震）
3. 播放**警报音**（3 秒）
4. 点屏幕任意位置可解除

板子那边蜂鸣器同时响 10 秒后自动复位，手机收到状态恢复后也会自动收起遮罩。

## 五、CSV 记录

- 点「开始记录」后，每收到一帧数值就写一行
- 文件位置：`Android/data/com.bme.ppg/files/ppg_年月日_时分秒.csv`
- 表头：`timestamp_ms,spo2,pr,pi,pitch,roll,state`
- 取文件：用电脑数据线连接 → 找到上述路径，或用手机自带文件管理器的「Android/data」入口
- 记录时按钮变红显示「停止记录」，停止后 Toast 会提示完整路径

## 六、自动重连

- 蓝牙意外断开（走出范围、板子掉电、模块重置）时，App 自动每 3 秒重试，最多 5 次
- 状态胶囊会显示「重连中 n/5」
- 主动点「断开」不会触发重连

## 七、故障排查

| 现象 | 原因 | 处理 |
|---|---|---|
| 点胶囊弹窗为空 | 手机没和 JDY-31 配对 | 先去系统蓝牙配对 |
| 连接失败 | 电脑端上位机还连着 | 电脑端点断开（JDY-31 只能挂一台主设备） |
| 一直「重连中 n/5」 | 模块掉电或超出范围 | 检查模块灯、靠近板子 |
| 数值全 `--` | 板子没发数据 | 检查上电、固件、TX/RX 是否接反 |
| 质量条 0 格 + 「信号弱」 | 手指没盖住或按太轻 | 指腹完整覆盖，轻压 |
| 姿态 0°/0° | MPU6050 未接或初始化失败 | 检查 SDA/SCL 与供电 |
| 记录文件找不到 | 没开「所有文件访问」或路径没找对 | 用 `Android/data` 入口，或连电脑取 |

## 八、技术参数

- 蓝牙：经典 SPP（RFCOMM，UUID `00001101-0000-1000-8000-00805F9B34FB`），二维码配对后直连
- 串口参数：9600 8N1
- 帧协议：`AA 55 | type | len | payload | checksum(前 4+len 字节求和 &0xFF)`
  - `0x01` len=6：SpO2 / PR / PI(×0.1) / pitch+90 / roll+90 / state
  - `0x02` len∈{0,1}：跌倒事件
  - `0x03` len∈{6,12}：波形（12 字节为 ir0[3] red0[3] ir1[3] red1[3]，大端）
- 采样：25 帧/秒 × 2 点 = 50 Hz
- 脉率算法：IR 去直流（40 点均值）+ 5 点平滑 → 峰值（阈值 50%、最小间隔 22 点 = 上限 136 bpm）→ 中位间隔 + 剔除 35% 离群 → 60/平均间隔；峰峰值 < 1200 LSB 判「信号弱」不出值

# PPG_STM32 转接板 v6

v6 为当前实物版本，约 100×60 mm，Type-C 供电。相对 v5 的主要改动：

- 重绘并修正 S1–S4 按键接线，四键可独立使用（短按/长按）
- 修正 J3（MPU6050）接口，保留 I2C1 与 INT 连接
- 增加 Type-C 供电入口
- 保留 MAX30102、SH1106 OLED、JDY-31、蜂鸣器等原有接口

## 说明

- v6 已导出 Gerber 打板包；打板前请在自己的立创 EDA 环境中复核 DRC、板框与器件封装。
- 18650 充放一体模块与电量 ADC 尚未接入，属于后续版本计划。
- v5 回退版在上一级 `PCB工程/`，仅用于对照，不作为当前实物版本。
